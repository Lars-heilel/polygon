# Landing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build public mobile-first landing at `/landing` from existing shared primitives with full noindex.

**Architecture:** New FSD package `@org/pages-landing` under `libs/client/pages/system/`, lazy public route in messenger router, static sections only, `robots.txt` in messenger `public/`.

**Tech Stack:** React + react-router, Tailwind v4 tokens, `@org/shared` Heading/Text/Button, Nx/vitest.

**Spec:** `docs/superpowers/specs/2026-09-09-landing-design.md`

## Global Constraints

- Import only from `@org/shared` root (never `@org/shared/src/...`).
- No new Tailwind tokens, no broad selectors in `global.css`; layout/geometry classes locally only.
- Exactly one `h1` on the page; stack blocks use `h2`; lists use `ul > li`.
- `robots.txt` content is exactly `User-agent: *` newline `Disallow: /` newline.
- TypeScript strict, no `any`; kebab-case files; explicit return types on exported functions.
- Run tasks via `npm exec nx`, never global `nx` or direct vite/jest.

- [ ] **Step 5: Write landing-page.tsx (meta robots + landmarks)**

```tsx
import { useEffect } from 'react';

import { LandingFooter } from './sections/landing-footer';
import { LandingHeader } from './sections/landing-header';
import { LandingHero } from './sections/landing-hero';
import { LandingStack } from './sections/landing-stack';

const ROBOTS_CONTENT = 'noindex, nofollow, noarchive';

function upsertRobotsMeta(): () => void {
  const previous = document.querySelector('meta[name="robots"]');
  const previousContent = previous?.getAttribute('content');
  let meta = previous as HTMLMetaElement | null;
  if (!meta) {
    meta = document.createElement('meta');
    meta.setAttribute('name', 'robots');
    document.head.appendChild(meta);
  }
  meta.setAttribute('content', ROBOTS_CONTENT);
  return () => {
    if (previous) {
      if (previousContent) previous.setAttribute('content', previousContent);
    } else {
      meta?.remove();
    }
  };
}

export function LandingPage(): JSX.Element {
  useEffect(() => upsertRobotsMeta(), []);

  return (
    <div className="flex min-h-screen flex-col bg-surface text-text">
      <LandingHeader />
      <main
        id="main"
        className="flex w-full flex-1 flex-col"
      >
        <LandingHero />
        <LandingStack />
      </main>
      <LandingFooter />
    </div>
  );
}
```
