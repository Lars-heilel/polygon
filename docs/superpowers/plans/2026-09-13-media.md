# media-service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SPEC-4: tight-контракты загрузки, паттерны из констант, RPC-ошибки со статусом, GC зависших PENDING, Gateway на `API_ROUTES` + валидация. Prisma + мост BigInt уже сделаны (коммит `09a5f09`).

**Architecture:** Контракты → lib-контроллер (константы паттернов) → сервис (RPC-статусы + GC) → Gateway (маршруты + pipe) → фронт-аудит. Миграций нет (схема финальна).

**Tech Stack:** NestJS + Prisma + MinIO (`IStorageProvider`), zod/`createZodDto`, Jest (`jest.mock('@org/core')`-фабрики), Nx из корня.

**Spec:** `docs/superpowers/specs/2026-09-13-media-design.md`

## Global Constraints

- Nx только из корня; `--testPathPatterns=`; `npm` эксклюзивно.
- Контракты first; маршруты только `API_ROUTES`; паттерны только из `MEDIA_PATTERNS` (строковые литералы `'media.*'` в хендлерах запрещены).
- Ошибки сервисов — Nest `HttpException`-семейство (`NotFoundException`), Gateway маппит через существующий `send()`.
- Логи: `eventType` + presence-флаги (сервис уже соответствует — не ломать).
- Спеки в `__tests__/`; живых broker/DB/MinIO в юнит-прогоне нет (repo/storage — моки).
- `nx sync` дважды после межпакетных импортов.
- Осознанный пропуск (YAGNI, фиксируется в отчёте): Redis-сторож `media:upload:{key}` не вводим —
  `confirmUpload` идемпотентен по построению (повторный confirm пишет тот же `READY`);
  планировщик GC не заводим — хендлер вызывается вручную/админом, шедулер в SPEC-7.

async listStalePending(olderThan: Date, take: number): Promise<File[]> {
  const rows = await this.prisma.file.findMany({
    where: { status: 'PENDING', createdAt: { lt: olderThan } },
    orderBy: { createdAt: 'asc' },
    take,
  });
  return rows.map((row) => this.toFile(row));
}

- Добавить:

```ts
async gcStalePending(olderThanHours: number, take: number): Promise<{ deleted: number; failed: number }> {
  this.logger.log({ eventType: 'media_gc_requested', olderThanHours, take });
  const stale = await this.repo.listStalePending(
    new Date(Date.now() - olderThanHours * 3_600_000),
    take,
  );
  let deleted = 0;
  let failed = 0;
  for (const file of stale) {
    try {
      await this.storage.delete(file.bucket, file.key);
      await this.repo.delete(file.id);
      deleted += 1;
    } catch {
      failed += 1;
    }
  }
  this.logger.log({ eventType: 'media_gc_done', deleted, failed });
  return { deleted, failed };
}
```
