# Инфраструктура — Техническое задание

> **Назначение:** Окружение для запуска и мониторинга

## 1. Окружение

| Компонент | Назначение |
|-----------|-----------|
| PostgreSQL | База данных каждого микросервиса |
| Redis | Кэш сессий, rate-limiting |
| RabbitMQ | Межсервисные очереди |
| MinIO | S3-совместимое файловое хранилище |
| Meilisearch | Поисковый движок |
| Prometheus | ~~Сбор метрик~~ — удалён, настройка с нуля |
| Grafana | ~~Дашборды мониторинга~~ — удалён, настройка с нуля |

Все компоненты запускаются через Docker Compose.

## 2. Запуск

```bash
# Полный локальный запуск
./scripts/bootstrap.sh          # Docker + DB + Prisma
npm run dev:all                 # Все сервисы

# Docker
npm run dev:docker:up           # Запустить инфраструктуру
npm run dev:docker:down         # Остановить

# Demo режим
npm run demo:start              # Production-like сборка
```
